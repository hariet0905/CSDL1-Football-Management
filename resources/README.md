# Tài nguyên dự án

- `design/`: ER hiện hành và ảnh mô hình tham khảo/lịch sử.
- `references/`: yêu cầu nghiệp vụ và tài liệu Word.
- `reports/`: báo cáo tổng hợp dự án.
- `local-backups/`: bản sao trigger/procedure tạo khi cập nhật DB; thư mục này bị Git bỏ qua.

Ảnh giao diện dùng lúc chạy vẫn ở `app/web/photos`, `app/web/crests` và `app/web/flags`; đây là tài nguyên sản phẩm, không phải file rác.
